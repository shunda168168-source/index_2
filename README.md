# 📊 台股配息年表

單一 HTML 檔案打造的台股配息查詢頁面，彙整 ETF 與熱門金融股的歷年配息紀錄，方便快速比較殖利率與除息頻率。

線上瀏覽：[配息年表頁面.html](配息年表頁面.html)

## 功能特色

- **雙分頁**：ETF 配息 / 熱門金融股配息，可切換檢視
- **搜尋與篩選**：依代號、名稱搜尋，並可依配息頻率（月配、季配、半年配、年配…）篩選
- **欄位排序**：點擊表頭依代號、股價、近12個月配息、估算殖利率、最近除息日等排序
- **估算殖利率**：以近12個月配息加總 ÷ 參考股價計算
- **配息明細**：展開每檔標的可查看近1-2年依年度分組的完整配息紀錄，以及已公告但尚未發放的未來配息
- **查詢連結**：每列提供奇摩股市、玩股網的外部連結，可查詢即時股價與完整配息紀錄
- **深色模式**：自動依系統設定切換淺色/深色主題
- **純前端**：無任何外部依賴，資料內嵌於頁面中，下載後即可離線開啟使用

## 使用方式

直接用瀏覽器開啟 [`配息年表頁面.html`](配息年表頁面.html) 即可，或透過 GitHub Pages 部署後線上瀏覽。
